# 科目一理论考试模拟系统

一个本地可打开的科目一机考界面模拟器，用来提前熟悉考试电脑上的常见布局和交互流程。

## 功能

- 模拟科目一 100 题、45 分钟、90 分合格的考试外壳
- 考生信息区、剩余时间、题目区、答题卡、上一题、下一题、确认本题、交卷
- 交卷确认弹窗、时间到自动交卷、成绩页
- 内置少量示例题，支持键盘 A/B/C/D 选项、方向键切题、Enter 确认
- 不依赖后端和构建工具，浏览器直接打开即可使用

## 使用方法

直接双击 `index.html`，或在本目录启动静态服务器：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

## 说明

这个项目的目标不是替代正式题库或刷题工具，而是帮助考生提前熟悉科目一考场机考页面的大致结构和操作节奏。

页面规则参考了公开的机动车驾驶人考试规则和常见仿真考试页面，包括：

- 科目一通常为 100 题、45 分钟、90 分合格
- 单选题、判断题为主要题型
- 交卷前确认，时间到自动结束考试

不同地区和不同考场的实际考试系统皮肤可能存在差异，请以当地车管所实际考试界面为准。
